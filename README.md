# Nakshatra 2026 — The Aerospace Hackathon

> **Flagship aerospace-focused hackathon organized by the Aerospace Club, Madhav Institute of Technology & Science (MITS), Gwalior.**

---

## Overview

**Nakshatra 2026** is a national-level aerospace hackathon uniting innovators, engineers, and researchers to address cutting-edge challenges across space science, autonomous aeronautics, satellite avionics, and astrophysics.

- **Registration Portal:** [Unstop Official Event Page](https://unstop.com/p/nakshatra-the-aerospace-hackathon-2026-madhav-institute-of-technology-and-science-mits-gwalior-1751540)
- **Venue:** Student Activity Center (SAC), MITS Gwalior Campus, Madhya Pradesh, India
- **Dates:** 24 – 25 October 2026 (Offline 12-Hour Hackathon)
- **Registration Deadline:** 26 September 2026, 10:08 PM IST
- **Prize Pool:** ₹10,000+ Cash Prize Pool, Winner Trophies, Finalist Swag Kits, and Official Certificates

---

## Core Features & Experience

- **3D WebGL Cosmic Environment:** Interactive Three.js starfield and event horizon accretion disk responsive to cursor dynamics.
- **Web Audio API Procedural Sound Engine:** Real-time sci-fi synthesized ambient cosmic drone, telemetry blips, and warp engagement audio without external audio file dependencies.
- **Interactive Telemetry HUD:** Real-time mission status, MITS Gwalior geographic coordinates (`26.2307° N, 78.2045° E`), live IST clock, and audio synthesizer toggle.
- **Live Countdown Timer:** High-precision T-minus clock calculating remaining time until the 26 September 2026 registration cutoff.
- **Dual Competition Tracks:**
  - **Software Track:** Orbital Mechanics, Telemetry Decoders, Space Debris Tracking, Computer Vision for Rover Navigation.
  - **Hardware Track:** CubeSat / CanSat Avionics, Thrust Vector Control (TVC), Planetary Rover Suspension, Long-Range RF Telemetry.
- **Interactive Chronology Matrix:** Master milestone roadmap alongside detailed Day 1 & Day 2 hourly event breakdowns (Build Sprints, Mentorship Sessions, Live Telescope Workshop).
- **Holographic Prize Vault:** ₹10K Cash Pool, Finalist Certificates, Exclusive Magazine Feature, and Goodies.
- **Query Resolution FAQ:** Expandable accordion answering eligibility, submission parameters, and logistics.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/connectGT/Aerospace-Hackathon-Website.git

# Navigate to project directory
cd Aerospace-Hackathon-Website

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```
